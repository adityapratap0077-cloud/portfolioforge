Privacy

PortfolioForge is a free tool by Aditya Pratap that turns a GitHub profile into a portfolio site. This page explains, in plain terms, what information it handles.

What the site handles

When you use PortfolioForge, you enter a GitHub username. The site reads that profile's public GitHub data (profile details, repositories and activity) to build the portfolio. That data is public on GitHub already; PortfolioForge does not ask for your GitHub password and cannot see private repositories. If you choose to drop in a resume file, it is used to build your portfolio.

Generating a portfolio on this site does not require an account.

How it is used

The information is used only to generate, display, download or share the portfolio you asked for. We do not sell your information to anyone.
