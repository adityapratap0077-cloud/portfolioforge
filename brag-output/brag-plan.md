# Brag Plan: PortfolioForge

## What is this app?
Type a GitHub username (or drop a resume) and get a full, editorial portfolio website in seconds — themed, typed, downloadable, shareable.

## The angle
The punchline is the contrast: every dev's GitHub looks the same — a wall of grey squares. PortfolioForge turns that raw public data into a crafted, paper-and-ink portfolio that reads like *you*. The video shows the actual flow: username typed in, "Forging portfolio…", then a real editorial portfolio lands with ranked repos.

## Hook (first 2-3 seconds)
Big serif type on paper: "Your GitHub is not your portfolio." — slams in word by word, accent period, then the stamp: PortfolioForge answers.

## Key moments (the middle)
- **The one text box:** the actual generator UI recreated — `@ | github username` with "torvalds" typed live, cursor taps "Generate". Verbatim copy: "Free to try · No sign-up needed · Only public GitHub data".
- **Forging → the portfolio:** spinner + "Forging portfolio…" cuts to a forged editorial hero (Linus Torvalds) with three repo cards arriving one by one: linux, subsurface, uemacs.
- **Make it yours:** six theme swatches (Paper, Ink, Moss, Clay, Slate, Bone) arriving on the beat; then one card: "Download HTML · Save to account · Share a link".

## Outro / punchline
"PortfolioForge." logo slam, italic closer "A portfolio that reads like *you*.", mono URL "portfolioforge-delta.vercel.app", mono kicker "FREE TO TRY · NO SIGN-UP NEEDED". Final bell rings over the music fade.

## User flow worth showing
Type GitHub username → tap Generate → "Forging portfolio…" → finished editorial portfolio with repos/stats → theme/typography/download/share. Entry → key action → result.

- Interpretation: restrained layouts, generous whitespace, serif display type; pacing comes from snappy entrances and the beat grid, not from loudness. Readable, confident, never shouting.
